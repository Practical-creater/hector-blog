BEFORE YOU START

阅读前必看

三件事，读完再往下。

1

别怕"终端"

那个黑框框就是"用打字代替点鼠标"的窗口。输入一行、按回车，电脑做一件事。跟微信发消息没本质区别，只是收消息的是电脑。不会把电脑弄坏。

2

命令请复制粘贴，不要手打

每个符号都有意义，手打极易漏。本页所有代码块右上角都有「复制」按钮，点一下就行。

3

输密码时屏幕不显示，是正常的

有些命令要你输 Mac 开机密码。打字时屏幕上什么都不会出现——不是卡住，是 macOS 的安全设计。照常输完回车即可。

GATEKEEPER

弹「已损坏」怎么办

首次打开时 macOS 大概率弹窗说「"Clash Verge"已损坏，无法打开」。这不是真损坏，是系统对未经苹果认证软件的拦截。

Terminal
$ sudo xattr -dr com.apple.quarantine "/Applications/Clash Verge.app"

回车后要你输密码

就是你的 Mac 开机密码。屏幕不会显示任何字符，照常输完回车即可。

另一种提示：「无法验证开发者」

走「系统设置 → 隐私与安全性」→ 拉到最底 → 找到那个应用 → 点「仍要打开」。

这行命令以后还会用到

任何从 GitHub 下载的应用被拦，都把引号里的路径换成对应的 .app 即可。

TROUBLE

报 EACCES 权限错误怎么办

⚠ 千万不要用 sudo npm install

那会让后续所有 npm 操作都要 sudo，越陷越深，是新手最常掉的坑。

正确做法是给 npm 换一个你有权限的目录：

Terminal
$ mkdir -p ~/.npm-global $ npm config set prefix ~/.npm-global $ echo 'export PATH="$HOME/.npm-global/bin:$PATH"' >> ~/.zshrc $ source ~/.zshrc $ npm install -g @anthropic-ai/claude-code

COMMANDS

Claude Code 常用命令

命令作用什么时候用
claude在当前文件夹启动每次开工
/help查看所有命令忘了有什么功能时
/model切换模型想换个模型试试
/clear清空当前对话聊久了变慢、答非所问时
/exit退出收工，或需要重启生效时

💡 /clear 是最实用的一个

AI 的"记忆"有上限，聊太久会塞满导致变慢、跑题。换个新话题时先 /clear，效果立刻回来。

THE METAPHOR

先用一个比喻讲清楚

Claude Code 和 Codex，就像两部不同品牌的手机。
一部 iPhone 一部安卓，操作习惯不同，但本质都是"能上网的设备"。

但光有手机打不了电话——还需要一张 SIM 卡和一个运营商套餐。

比喻实际是什么
手机Claude Code / Codex
SIM 卡API Key —— 一串 sk- 开头的字符
运营商套餐大模型厂商：DeepSeek、Anthropic…
卡槽管理器CC Switch —— 插多张卡、一键切换

同一张卡可以插进不同的手机

但信号制式不一样 —— 这就是下面最容易填错的地方。

HOW IT WORKS

原理：AI 不替你点鼠标

先纠正一个常见误解：AI 不会去操作 Stata 的图形界面帮你点菜单。它做的是另一件更高效的事——

01 你说人话 "帮我跑个引力模型"
→
02 AI 写 .do Stata 的脚本
→
03 后台运行 不开图形界面
→
04 生成 .log 所有输出都在里面
→
05 AI 读结果 看懂数据 / 看懂报错
报错就自己改了重跑

这是一个闭环

报错信息就在 .log 里，AI 读到后自己改 .do 再跑一遍，直到跑通。你全程只说中文。

但代码你得看得懂

答辩时是你在台上。它写的每行都该让你能解释。

gravity.do
* ---------- 1. 生成模拟数据 ---------- * 真实研究中，这里换成 import excel 读你自己的数据 clear all set more off set seed 12345 set obs 500 gen country_i = ceil(_n/20) // 出口国编号 gen country_j = mod(_n, 20) + 1 // 进口国编号 drop if country_i == country_j // 剔除自己跟自己贸易 gen gdp_i = exp(rnormal(10, 1)) // 出口国 GDP gen gdp_j = exp(rnormal(10, 1)) // 进口国 GDP gen dist = exp(rnormal(8, 0.5)) // 两国距离（公里） * 按引力模型的理论关系生成贸易额，再加随机扰动 gen trade = exp(0.8*ln(gdp_i) + 0.8*ln(gdp_j) - 1.1*ln(dist) /// + rnormal(0, 0.5)) * ---------- 2. 取对数：系数直接读作弹性 ---------- gen ln_trade = ln(trade) gen ln_gdp_i = ln(gdp_i) gen ln_gdp_j = ln(gdp_j) gen ln_dist = ln(dist) * ---------- 3. 描述性统计 ---------- summarize ln_trade ln_gdp_i ln_gdp_j ln_dist * ---------- 4. 引力模型回归 ---------- regress ln_trade ln_gdp_i ln_gdp_j ln_dist, robust

TOP 3

最常见的三个问题

1

装完了却说 command not found

① 关掉终端窗口，重新开一个（解决 90%）　② 还不行跑 source ~/.zshrc; hash -r　③ 再不行重启电脑。
原因：终端只在启动时读一次"命令清单"，不重开就看不见新装的东西。

2

下载卡住 / 连接超时

查 Clash Verge 的 Tun 模式是否打开，然后 curl -I https://www.google.com 要看到 HTTP/2 200。还不行就在终端里单独设代理（端口在 Clash 的「设置 → 端口设置」里看）：

单独给终端设代理
$ export HTTPS_PROXY=http://127.0.0.1:7897 $ export HTTP_PROXY=http://127.0.0.1:7897
3

「XXX 已损坏，无法打开」

不是真损坏，是 macOS 拦截未认证软件：sudo xattr -dr com.apple.quarantine "/Applications/应用名.app"
